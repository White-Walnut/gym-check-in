If something goes wrong, this saves a record of what happened so it can actually be looked into -- it never leaves this PC on its own. Export it and send the file if you're asked to.

Kiosk lockdown

Makes the customer-facing check-in display fullscreen and blocks Alt+F4 and its close button, so a member at the desk can't casually exit or minimize it. This is a deterrent, not a full lockdown — the Windows key, Ctrl+Alt+Delete, and Task Manager still work and are outside any app's control. Turning this off always works from here, since reaching this screen already required the staff PIN. Only takes effect when two-screen mode below is also on — there's no customer-facing display otherwise, so this has no effect on your own staff dashboard.

Two-screen mode

When two monitors are connected, use one purely for check-in results and the other purely for staff (no more switching between them). Only takes effect the next time the app starts, and only when a second display is actually detected.

Data retention

Check-in records older than this are deleted automatically each time the app starts. Member profiles and payment/renewal history are not affected by this setting.
